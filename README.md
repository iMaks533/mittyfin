Mittyfin — компактный клиент медиасервера [Jellyfin](https://jellyfin.org) в духе Yamby: тёмный
интерфейс, постеры, «Продолжить просмотр», карточки с логотипами. Главное в нём — плеер,
который показывает **Dolby Vision profile 7 с полным слоем улучшения (FEL)** на обычных
телефонах и приставках. Таких дисков в ремуксах большинство, а честно воспроизвести их
умеют лишь редкие плееры с двухслойным декодером Dolby. Mittyfin собирает кадр сам: два
аппаратных HEVC-декодера и шейдер на GPU.

|---|---|

> Скриншоты HDR-кадров система сохраняет в SDR: яркие насыщенные цвета упираются в предел, и часть
> разницы теряется. На самом экране картинка ярче и контрастнее, а мерцание тестовой надписи видно только вживую.

### Зачем это нужно

Ремуксы UHD Blu-ray с Dolby Vision почти всегда в **profile 7**: под HDR10-базой лежит второй
видеослой (EL) и метаданные (RPU). У дисков с **FEL** (Full Enhancement Layer) слой улучшения
несёт реальные детали картинки, а не только метаданные. Обычные плееры его выбрасывают и
показывают голый HDR10. Двухслойный декодер Dolby есть в считаных приставках, а в телефонах
его нет совсем.

### Как это работает

```
            ┌─ BL 3840×2160 ─► HEVC-декодер №1 (P010) ─┐
 файл P7 ──►│                                          ├─► шейдер GLES 3.0 ─► тон-маппинг ─► экран
 (1 дорожка)├─ EL 1920×1080 ─► HEVC-декодер №2 (P010) ─┤    reshaping BL      BT.2390        PQ BT.2020
            └─ RPU ─────────► libdovi ────────────────┘    + остаток FEL     по сценам      или SDR
```

1. Каждый кадр дорожки делится на базовый слой (BL), слой улучшения (EL) и RPU.
2. BL и EL декодируются **двумя обычными аппаратными HEVC-декодерами** в 10-битный P010.
3. RPU разбирается библиотекой [libdovi](https://github.com/quietvoid/dovi_tool): из неё берутся кривые и матрицы композитора.
4. Шейдер собирает кадр так же, как это делает Dolby: reshaping базы (полиномы или MMR), добавление остатка FEL
   (NLQ, деквантование до апскейла), цветовое преобразование в PQ BT.2020. Логика повторяет
   [libplacebo](https://code.videolan.org/videolan/libplacebo).
5. **Динамический тон-маппинг BT.2390** по пиковой яркости каждой сцены из RPU:
   - на HDR-экране — к пику панели, выход остаётся PQ, на окно ставятся метаданные SMPTE 2086 / CTA-861.3;
   - на SDR-экране — к белому 250 нит с гаммой BT.709;
   - сцены, которые и так помещаются в возможности экрана, не трогаются.
6. Кадры показываются по vsync: на 120 Гц кадр 24p держится ровно пять обновлений, без рывков 3:2.

MEL и P7 без слоя улучшения идут тем же путём: база + RPU + тон-маппинг.

### Что нужно от устройства

Проверка встроена в приложение: в настройках рядом с переключателем написано, подходит ли устройство и почему.

| Требование | Зачем |
|---|---|
| Android 10 и новее | API декодеров и EGL |
| Аппаратный HEVC Main10 с выходом **P010** | 10 бит на компоненту для обоих слоёв |
| **Две одновременные сессии 4K** | BL и EL декодируются параллельно |
| EGL `EGL_EXT_gl_colorspace_bt2020_pq` + RGBA1010102 | HDR-вывод. Без него картинка идёт в SDR с тон-маппингом |

| Устройство | Результат |
|---|---|
| OPPO Find X9 Pro (MediaTek, `c2.mtk.hevc.decoder`) | ✅ FEL, HDR-вывод, 4K24, кадр на GPU ≈ 10–15 мс |
| NVIDIA Shield (Android 11) | ❌ декодер отдаёт только 8 бит, HDR-окна нет — ограничение железа |

Если поток не подходит (DRM, нестандартный RPU, смена разрешения, ошибка декодера), плеер
сам переключается на обычный MediaCodec с той же позиции. Причина видна в статистике в строке «Откат».

## Каталог

### Вход

Адрес сервера, пользователь и пароль. Адрес можно ввести как угодно: `192.168.1.5`, `nas`,
`https://media.example.com`, `http://nas/jellyfin`. Схема `http://` и порт `:8096` подставятся
сами, явный порт и путь за реверс-прокси сохранятся. **Пароль не хранится** — только токен
сессии. Она переживает перезапуск и выгрузку приложения из памяти. «Выйти» отзывает токен на сервере.

### Главная

<p align="center">
  <img src="docs/screenshots/home.webp" width="32%" alt="Главная">
  <img src="docs/screenshots/home-rows.webp" width="32%" alt="Ряды на главной">
</p>

Сверху вниз:

- **Карусель новинок** — 10 последних фильмов и сериалов: фон, логотип, рейтинг, жанры, год. Листается свайпом или стрелками пульта.
- **Медиатеки** — плитки всех библиотек сервера.
- **Продолжить просмотр** — с плашкой «Осталось: 1ч 12м» и полоской прогресса. Позиция общая со всеми клиентами Jellyfin.
- **Следующие серии** — что смотреть дальше в начатых сериалах.
- **Новое по каждой медиатеке** с кнопкой «Ещё».

На постерах: рейтинг в уголке, синий кружок с числом непросмотренных серий, полоска прогресса.
Потяните экран вниз, чтобы обновить.

**Меню карточки** — долгое нажатие (на пульте зажатая OK или кнопка Menu): открыть, открыть сериал,
отметить просмотренным или непросмотренным, добавить в избранное или убрать оттуда,
убрать из «Продолжить просмотр» (позиция сбрасывается, без отметки «просмотрено»),
скрыть серию из «Следующих серий», скрыть медиатеку с главной.
Всё скрытое возвращается в настройках, раздел «Главная».

### Жесты

- **Двойной тап** по левой трети — назад на шаг, по правой — вперёд, по центру — пауза.
- **Удержание** — временная скорость 2× («2× ▶▶»), отпустили — обычная.
- **Свайп вверх-вниз** по левой половине — яркость, по правой — громкость, с подсказкой в процентах.
  Края экрана оставлены системным жестам.

| Клавиша | Действие |
|---|---|
| ← / → | Перемотка на шаг. На полосе перемотки удержание разгоняется до 30, 60 и 120 с |

### Звуковые дорожки и субтитры: какие выбираются сами

**Звук:**
- Язык из памяти тайтла, иначе из настроек (по умолчанию русский).
- Нет дорожки на этом языке — берётся дорожка сервера по умолчанию.
- При «Предпочитать lossless» среди дорожек нужного языка выбирается без потерь с наибольшим
  числом каналов: TrueHD, FLAC, ALAC, PCM, DTS-HD MA.

**Субтитры — режим «Когда включать»:**

| Режим | Что происходит |
|---|---|
| **Умный** (по умолчанию) | Звук не на вашем языке — полные субтитры. Звук на вашем — только принудительные (надписи, иностранная речь) |
| Всегда на моём языке | Полные субтитры, обычные раньше SDH |
| Только принудительные | Forced на языке субтитров, иначе на языке звука |
| Как на сервере | Дорожка по умолчанию из файла |
| Выключены | — |

**Память по тайтлу.** Выбрали вручную — запомнилось для этого фильма или для всего сериала:
язык звука, субтитры (или «выкл.»), forced, сдвиг субтитров, скорость. Следующие серии
стартуют с этим выбором. Хранятся последние 400 тайтлов.

### Оформление субтитров

<img src="docs/screenshots/player-subtitle-style.webp" width="49%" align="right" alt="Вид субтитров">

**«Вид субтитров»** меняется прямо на кадре:
- размер 50–200 %;
- шрифт: системный, плотный, узкий, с засечками, моноширинный;
- контур: обводка, тень, подложка, без контура;
- цвет: белый, жёлтый, голубой, зелёный;
- положение: ниже, обычно, выше; жирный шрифт;
- «Стили из файла (ASS, VTT)» — уважать оформление автора или показывать всё одинаково.

**Сдвиг субтитров** — шагами 0,1 и 1 с в пределах ±60 с, запоминается для тайтла.

**libass** рисует ASS/SSA с родными шрифтами, позициями и эффектами — встроенные в MKV и
внешние. Для аниме это обязательно.

**Кодировка.** Старые SRT в Windows-1251 распознаются и читаются без «кракозябр».

**Пометки для глухих.** По желанию из текстовых субтитров убираются `[музыка]`, `(стук)`, `♪…♪` и `ИМЯ:`.

Внешние субтитры с сервера подключаются как отдельные дорожки.

### Звук: задержка и усиление

<img src="docs/screenshots/player-audio.webp" width="49%" align="right" alt="Звук: задержка и громкость">

- **Задержка звука** шагами 50 мс и 0,5 с. Запоминается **отдельно для каждого устройства
  вывода**: динамик, проводные и USB-наушники, HDMI, каждые Bluetooth-наушники по имени.
  Подключили AirPods — подставилась их задержка.
- **Усиление громкости** до +12 дБ для тихих ремуксов.
- **Голоса** — отдельное усиление центрального канала 5.1/7.1, от −6 до +12 дБ.
- Пики мягко ограничиваются, без хрипа.
- **FFmpeg-декодеры** TrueHD, DTS и других форматов включаются, если на устройстве нет своих.
- Отключили наушники или пропал Bluetooth — пауза, а не внезапный звук из динамика.

<br clear="right">

### Сериалы: пропуск заставок и «Далее»

<img src="docs/screenshots/player-episodes.webp" width="49%" align="right" alt="Панель серий">

- **Пропуск отрезков** с сервера (Jellyfin 10.10+, плагин Intro Skipper): заставка, пересказ,
  титры, анонс. Кнопка «Пропустить …» или автопропуск для каждого типа отдельно.
  Если титры идут до конца файла, пропуск сразу открывает следующую серию.
- **Карточка «Далее»** появляется с началом титров (или за 40 с до конца): кадр, название,
  «Смотреть · 10» с отсчётом и «Отмена».
- **Автопереход** на следующую серию по окончании отсчёта.
- **«Вы ещё смотрите?»** — после нескольких серий подряд без касаний плеер ставит паузу и
  закрывается через минуту, если никто не ответил.
- **Панель «Серии»** прямо в плеере: сезоны, кадры, просмотренные отмечены. Тап — и серия
  запускается в том же окне.

<br clear="right">

### Перемотка: главы и превью

- **Главы** — зазоры на полосе перемотки, название текущей главы под видео, список «Главы» с переходом.
- **Превью кадров** над полосой при перетаскивании: trickplay с сервера, а если его нет —
  кадр из самого файла. На MediaTek системный извлекатель отдаёт чёрное для 4K HDR, тогда
  остаются время и глава.

### Картинка в картинке, медиакнопки, таймер сна

- **PiP** (телефон): кнопкой или автоматически при сворачивании. В окне — перемотка и пауза.
  Пропорции окна по видео.
- **MediaSession:** кнопки гарнитуры, Bluetooth-пульты, медиашторка с обложкой и названием серии.
- **Таймер сна:** 15 мин – 2 ч. За 15 с до паузы звук плавно затихает, в углу виден остаток «☾ 23 мин».

### Частота экрана

- **Телефон:** режим с частотой, кратной кадрам фильма (24p → 120 Гц), переключение без мигания.
- **ТВ:** родная частота фильма по HDMI (23,976 Гц).
- После выхода из плеера частота возвращается.

### Перекодирование и ошибки

- **Качество:** оригинал или ограничение 40/20/10/6/3 Мбит/с — сервер перекодирует в HLS
  (HEVC или H.264, AAC/AC3/EAC3) для просмотра вне дома. Графические субтитры при этом вшиваются в картинку.
- **Файл не играет** на устройстве — тост «Файл не воспроизводится напрямую — перекодирование
  на сервере» и продолжение с той же секунды.
- **Сеть пропала** — до трёх переподключений («Переподключение… (2 из 3)»).
- **Поток завис** дольше 30 с — перезапуск с той же позиции.
- Позиция, старт и остановка отправляются на сервер: «Продолжить просмотр» совпадает на всех устройствах.
- Токен передаётся в заголовке, а не в адресе потока.

### Статистика

«Ещё → Информация о медиа» — панель, обновляемая раз в секунду: разрешение, частота и кодек,
режим (прямое воспроизведение или перекодирование), битрейт, скорость сети, буфер, пропущенные
кадры, звук. Для Dolby Vision — тип слоя (FEL / MEL), путь GPU FEL, время кадра на GPU,
тон-маппинг. Тап по панели переключает отладочный вид: «BL + RPU + EL», «без EL» для сравнения
и «только остаток EL ×32».

## Установка

1. Скачайте `Mittyfin-X.Y.Z.apk` со страницы [Releases](https://github.com/iMaks533/mittyfin/releases).
2. Установите на телефон или приставку (Android 10+, arm64).
3. Введите адрес своего сервера Jellyfin, пользователя и пароль.

Релизы подписаны одним ключом, поэтому новые версии ставятся поверх без потери входа и настроек.
Самостоятельно собранную debug-версию поверх релиза поставить нельзя (и наоборот): сначала удалите установленную.

## Сборка из исходников

Нужны JDK 17, Android SDK (compileSdk 36), NDK и CMake 3.22.1 для JNI-моста к libdovi.

```bash
./gradlew :app:assembleDebug
```

Тесты:

```bash
./gradlew :fel:testDebugUnitTest :app:testDebugUnitTest
```

```bash
./gradlew -p buildSrc test
```

Подписанный релиз собирается при наличии ключа. Путь и пароли задаются в `~/.gradle/gradle.properties`
(`mittyfin.storeFile`, `mittyfin.storePassword`, `mittyfin.keyAlias`, `mittyfin.keyPassword`),
без них получится неподписанный APK.

```bash
./gradlew :app:assembleRelease
```

Готовый файл: `app/build/outputs/apk/release/Mittyfin-X.Y.Z.apk`.

> Путь к проекту должен быть латиницей: Android Gradle Plugin не собирает из каталога с кириллицей.

**Устройство проекта:**

| Модуль | Что внутри |
|---|---|
| `app/` | Интерфейс на Jetpack Compose, клиент Jellyfin (REST + OkHttp), плеер на Media3 ExoPlayer: дорожки, субтитры, сериалы, PiP, MediaSession |
| `fel/` | GPU FEL: Media3-рендерер с двумя MediaCodec, разбор кадров на BL/EL/RPU, OpenGL ES-композитор и шейдеры, тон-маппинг, JNI к libdovi |
| `buildSrc/` | Версия приложения из git-тегов |

## Версии и релизы

Версия берётся из git: релиз — это тег `vX.Y.Z`. На помеченном коммите версия ровно `X.Y.Z`,
после него — `X.Y.Z-N-gхеш`, с незакоммиченными правками добавляется `-dirty`.
versionCode равен числу коммитов, поэтому каждая следующая сборка ставится поверх предыдущей.
Номер видно внизу настроек; он же уходит на сервер Jellyfin.

## Ограничения

- **GPU FEL** нужен 10-битный аппаратный HEVC с двумя сессиями 4K. На NVIDIA Shield его нет:
  там Dolby Vision P7 показывается обычным путём.
- **ColorOS** (OPPO, OnePlus) через несколько секунд без касаний опускает экран до 60 Гц
  функцией «OTI». Из приложения это не обойти.
- **Превью из файла** на MediaTek для 4K HDR недоступны — включите trickplay на сервере.
- Сборка только под **arm64-v8a**.
